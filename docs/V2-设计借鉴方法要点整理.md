## 1. 课程定位

- V1 是**起点，不是终点**；本课不教从零建主页，而是讲 V1 之后如何让它更像"自己的作品"。
- 核心：不再只对 AI 说 "Make it better."，而是**带着参考网站、截图、设计元素、组件和明确的审美判断**与 AI 合作改进。
- 痛点：你可能知道"这样更好看"，但说不清为什么、也不知道它叫什么。
- 本课提供：**词汇 + 资源 + 方法 + 版权底线**。

核心思想：From First Version to Your Version。
推荐流程：**Find → Analyze → Select → Adapt → Integrate → Test → Personalize**。

## 2. 浏览网站时看什么（Part 1）

- **Don't copy first. Observe first.**（先观察，再借鉴）
- 看到喜欢的网站，先问自己：
  - 我喜欢的是整体风格，还是某个局部？
  - 它属于什么风格？Minimal / Dark / Academic / Tech / Playful / Portfolio？
  - 我喜欢哪个网页元素？Hero、Navbar、Card、Grid、Animation？
  - 我能否用自己的内容重新实现类似效果？
  - 这个资源是只能参考，还是可以下载、Clone、Fork 或 Remix？

### 四个借鉴层级（Level 1 → 4）

| Level | 借鉴对象 | 推荐方式 | 通常是否需下载 |
|---|---|---|---|
| Level 1 | Inspiration / 整体灵感 | URL + Screenshot + What I Like | 不需要 |
| Level 2 | Design Elements / 具体设计元素 | 截图 + 指定区域 + 描述喜欢什么 | 通常不需要 |
| Level 3 | Components / 组件 | 组件代码或文档 + AI 判断兼容性 | 可能需要 |
| Level 4 | Templates / 模板 | Clone / Fork / Remix **+ 检查 License** | 通常需要 |

> 规律：层级越高越接近"拿来用"；层级越低越接近"学思路"。

## 3. 推荐资源（Part 2–4）

### 找灵感（Part 2）
| 资源 | 定位 | 适合借鉴 |
|---|---|---|
| **Land-book** | 设计灵感站，找整体风格/Portfolio/Landing Page/布局/色彩/字体 | Hero 排版、Projects 布局、极简/深色风格、大留白、卡片布局 |
| **Lapa Ninja** | 大量 Landing Page 与 Portfolio 案例库 | Hero、About Me、Project Cards、Skills、Contact、一页式滚动、Bento Grid |
| **Awwwards** | 世界顶级创意设计展示 | 首屏冲击力、文字层级、色彩氛围、适度动画（**不建议模仿复杂 3D/WebGL/大型动画**） |
| **CodePen** | 前端小效果、HTML/CSS/JS 交互示例 | 按钮动画、Card hover、图片放大、打字机、背景动效、导航交互 |

> 示例 Prompt 要点：找灵感后交给 AI 分析，**明确要求不复制其文字、图片、品牌与源码**；请 AI 挑出"能安全适配初学者主页的简单设计点"。

### 组件资源（Part 3，Reuse or Recreate）
- **Magic UI**：Bento Grid、Typing Animation、Shimmer Button、Marquee、Particles、Blur Fade、Dock 等。
- **Aceternity UI**：Hero Sections、背景、Cards、文字动画、Navbars、Hover、Parallax、Spotlight 等。
- **shadcn/ui**：Button/Card/Dialog/Tabs/Accordion/Form/Dropdown/Navigation/Table，理解"组件化设计"。
- 注意：这些多依赖 **React / Next.js / Tailwind / Motion**；纯 HTML/CSS/JS 项目**不应直接复制粘贴**，应让 AI 判断兼容性，**借鉴效果而非直接安装**。（术语：Next.js 是基于 React 的框架，额外提供路由、渲染、打包、部署优化。）

### 模板资源（Part 4，Start from Templates）
- **Framer Templates / Webflow Templates**：学习完整个人主页的结构与 Section 顺序、视觉节奏、响应式布局；不一定要用工具本身。
- **GitHub Portfolio Templates**：最接近学生实操，也是 GitHub Pages 部署的重要来源；**必须检查 README / License / 技术栈 / 是否适合 GitHub Pages / 是否需要署名 / 是否允许修改和发布**。

## 4. 网页设计术语（Part 5，知道它叫什么）

> 术语是"你和 AI 沟通的共同语言"。推荐查词站：https://namethatui.com/

### 结构类
| English | 中文 | 解释 |
|---|---|---|
| Hero Section | 首屏主视觉区 | 打开网页最先看到的大区域：大标题、副标题、按钮、背景图 |
| Bento Grid | Bento 网格 / 便当盒式布局 | 由不同大小卡片组成的网格布局 |
| Card | 卡片 / 信息卡片 | 独立信息块，如项目卡片、技能卡片 |
| Sticky Navigation | 粘性/固定导航栏 | 页面滚动时仍停在顶部或侧边 |
| Gradient | 渐变 / 渐变色 | 颜色平滑过渡 |
| Glassmorphism | 玻璃拟态 / 毛玻璃风格 | 半透明 + 模糊背景 |

### 交互与排版类
| English | 中文 | 解释 |
|---|---|---|
| Hover Interaction | 悬停交互 | 鼠标移到按钮/卡片/图片上的变化 |
| Scroll Animation | 滚动动画 | 滚动时内容淡入、移动、出现或变化 |
| Parallax | 视差滚动 | 前景与背景移动速度不同 |
| Typography | 字体排版 | 字体、字号、粗细、行距、标题层级 |
| Whitespace | 留白 | 有意识保留的空白 |
| Microinteraction | 微交互 | 按钮轻弹、图标旋转、输入框高亮等细节 |

### 在个人主页的应用（含 Prompt 示例）
- **Hero Section**：自我介绍 + 大标题 + 简短描述 + 按钮 + 背景/视觉元素。
- **Bento Grid**：适合 Skills / Projects / Interests / Learning Journey / Tools / Future Goals。
- **Card**：Project / Skill / Course / Experience / Interest 卡片（标题、简介、技术标签、hover）。
- **Sticky Navigation + Border Radius + Drop Shadow**：导航固定置顶、圆角统一、卡片加柔和投影制造层次。
- **Gradient**：Hero 背景、标题关键词、按钮、分隔线、卡片边框。
- **Glassmorphism**：顶部导航、个人介绍卡片、联系方式卡片、浮动按钮、技能卡片。
- **Parallax**：Hero 背景等；**初学者少用，避免影响手机端**。
- **Hover / Scroll / Microinteraction**：给主要 section 加克制的淡入 + 轻微上移；微交互少量即可，避免动画过多。
- **Typography / Whitespace**：建立清晰层级、增加呼吸感"但不要太空"。

## 5. 如何让 AI 提取你想要的设计（Part 6）

- 原则：**先分析，再修改**；不要一上来就说 "Modify my website"。
- 推荐顺序：**Analyze reference → Identify what I like → Check compatibility → Propose a plan → Then modify**。
- 推荐 Prompt 模板：在改代码前，先分析参考并说明——它用了哪些设计元素 / 哪些适合我的主页 / 哪些可能太复杂 / **是否有版权或许可问题** / 计划如何用我的内容来适配。
- 强调：给 AI 一个"**分析任务**"，而不是一个"**照抄指令**"；给它清晰边界与约束（**不复制文字/图片/品牌/源码**）。

### 四种输入方式（递进）
1. **URL + Screenshot + What I Like**（第一选择）：URL 给上下文，截图标位置，What I Like 表达审美判断。
2. **Screenshot Only**（第二选择）：AI 无法访问网站时，截图也能用（可裁剪、圈注、箭头标注）。
3. **Component Code / Repository**（第三选择）：适合 CodePen、Magic UI、Aceternity UI、GitHub 项目。
4. **Full Template**（第四选择）：适合 Framer、Webflow、GitHub Templates——**分析结构而非照抄**。

## 6. 与本项目的衔接

- 本项目现状：纯静态 HTML/CSS/JS（无构建依赖），V1 已完成并通过验收。
- V2 目标方向（建议，待与用户确认）：在**纯静态、轻量、移动优先**前提下，借鉴上述"风格/布局/交互思路"，做**自己的重新实现**。
- 候选可借鉴点（均为"思路"层，绿灯）：Hero 排版与留白、Bento Grid 技能区、Card hover、Sticky Navigation、克制的滚动淡入、少量微交互。
- **任何进入成品的素材，必须先在 `docs/V2-素材许可台账.md` 登记并通过黄灯核验。**
