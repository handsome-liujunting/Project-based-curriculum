## 二、黄灯资源许可核验（四要点）

### R-106 / R-107 两份字体子集

| 核验项 | 结论 |
|---|---|
| 1. 是什么许可？ | SIL Open Font License, Version 1.1（两份相同） |
| 2. 是否允许商用？ | ✅ 允许。OFL §1 允许自由使用、研究、修改、再分发，**不限制商业用途**；唯一的限制是不得**单独出售字体本身** |
| 3. 是否需要署名？ | OFL 不要求"署名"这一形式，但要求**随字体分发版权声明与授权全文**（§2）。两份授权全文已随文件放在 `assets/fonts/` 下 ✅ |
| 4. 是否允许修改和再发布？ | ✅ 允许（§3、§5）。V3.5 的 `text=` 子集化属于 Modified Version，仍以 OFL 分发 ✅ |

**关键核验（V3.5 复核）**：两份 OFL.txt 的版权声明之后**均无 Reserved Font Name（保留字体名）声明**，
因此按 §3，子集化后的版本**可以继续使用原名**，无需改名。已逐字复核原文。

### 子集化（Modified Version）说明

- **为什么子集化**：中文字体完整包通常 5–10 MB，直接用于静态页会明显拖慢首屏；
  拉丁字体整包也含大量本页用不到的字符。使用 Google Fonts 的 `text=` 接口只请求页面实际用到的字形。
- **V3.5 产物**：中文 **293 个字形 → 30 452 B**；拉丁 **50 个字形 → 8 648 B**。合计 **39 100 B（约 38 KB）**。
- **遵守 OFL 的做法**：① 仅删减字形、未改动字形设计；② 继续以 OFL 分发；
  ③ 随附两份授权全文；④ 因无 RFN，保留原字体名。
- **副作用（需知，已写入发布清单）**：子集是静态的，**新增汉字必须重新生成子集**，
  否则新字会回退到系统字体、与其余文字不一致。
  重建命令与各版本参考字节数见 `docs/V3.5-发布检查清单.md` 第 2 节，
  脚本为 `tools/resubset.ps1`，字体目录说明见 `assets/fonts/README.md`。
