### 备选（SQL 一直不通就用这个，图形化建表，完全不需要 SQL）

在 Supabase 里用 `Table Editor` 手工建两张表，字段如下：

`feedback` 表（私密反馈）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int8 | 主键，勾选 identity / 自动生成 |
| name | text | 可空 |
| relation | text | 可空 |
| device | text | 可空 |
| message | text | 必填 |
| version | text | 可空 |
| created_at | timestamptz | 默认 `now()` |

`messages` 表（公开留言板，只放"公开也没关系"的三样东西）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int8 | 主键，勾选 identity / 自动生成 |
| name | text | 可空（留空时页面显示「匿名」） |
| message | text | 必填 |
| created_at | timestamptz | 默认 `now()` |

建完表后，两张表都要：

1. 打开 `RPC/Policies` 里的 RLS（Enable RLS）
2. `feedback`：只加一条 INSERT 策略，允许 `anon` + `authenticated`（**不要**加 select 策略）
3. `messages`：加一条 SELECT 策略（允许 `anon` + `authenticated`）+ 一条 INSERT 策略
   （**不要**加 update / delete 策略）

> 注意：Supabase 新版把匿名角色叫 `anon`，前端用 publishable key 时就落在这个角色上。
> 若图形界面里策略面板要求填 `USING` / `WITH CHECK`，两处都填 `true` 即可。
