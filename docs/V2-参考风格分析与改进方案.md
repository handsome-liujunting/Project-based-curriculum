## 4. 设计规范提案（待用户确认）

### 配色（三选一，或提出你的偏好）
| 方案 | 主色 | 辅助 | 氛围 |
|---|---|---|---|
| A 活力橙 | `#FF6B35` | 深灰 #1F2937 / 米白 #FFF8F3 | 热情、运动感（贴合篮球） |
| B 电光紫 | `#7C3AED` | 青 #22D3EE / 深底 #0F172A | 潮酷、科技感 |
| C 柠檬黄绿 | `#84CC16` | 靛蓝 #4F46E5 / 米白 | 清爽、年轻 |

### 字体
- 方案：系统字体栈优先（零依赖、加载快、无版权风险）
- 标题加粗、正文常规；如后续要用网络字体，必须**先查 License 并登记台账**（🟡）。

### 交互（克制）
- 卡片 hover 轻抬升 + 阴影
- 主要 section 滚动淡入上移（IntersectionObserver）
- 导航粘性置顶
- 少量微交互（按钮、徽章）

### 技术约束
- 继续纯静态 HTML/CSS/JS，无构建依赖，移动优先，可 GitHub Pages 部署。
