## 1. 缘起

用户在 V2 完成后上传了一张个人作品集网站截图 `flowman-2.jpg`（美漫 / 超级英雄风格），
要求：**模仿该图的风格，但要更"活泼"**，并且**先给出反馈和样本，由用户决定是否改动**。

因此本轮分两步走：

1. 先做**风格分析 + 可评估的样本**，让用户看到实物再决定；
2. 用户确认后再落地为正式版本。

## 3. 参考风格拆解：什么能借，什么不能碰

### ✅ 可以借鉴的（**通用设计语言**，不专属于任何人）

| 元素 | 参考图的做法 | V3 的原创实现 |
|---|---|---|
| 主视觉 | 漫画城市天际线 + 英雄角色 | CSS 自绘天际线（9 栋楼 + 黄色窗点）；**不绘制任何角色** |
| 标题 | 超粗描边字 + 硬阴影 | `-webkit-text-stroke` + `text-shadow` 多层硬阴影 |
| 质感 | halftone 网点 | `radial-gradient` 平铺自绘网点 |
| 版面 | 分镜面板 + 粗边框 | `.panel` 组件（4px 黑边 + 7px 硬阴影） |
| 对话 | 气泡 + 三角尾巴 | CSS 气泡，`::after`（黑描边）+ `::before`（白填充）双层三角 |
| 配色 | 红 / 蓝 / 黄 / 粉大色块 | 自定义同色系 HEX（见下） |
| 装饰 | 拟声词、"条码" | 自创"叮！"（`clip-path` 星形）+ CSS 自绘条码 |

### ❌ 绝对不能碰的（**受版权保护的具体表达**）

- 品牌名 `FLOWMAN!` —— 换成用户本人的名字
- 任何角色形象、插画、图形 —— **一个都不复制**，改为 Emoji + CSS 自绘
- 原文案 —— 全部重写为本人信息
- 任何 Logo —— 不使用

> 判断依据：**Copy the idea, not the assets.**
> 风格（类型 / 设计语言）不受版权保护，具体表达受保护。这条界线就是本轮所有取舍的标准。

## 4. 设计规范（Design Tokens）

```css
--red:    #E14B32;   /* 主色：能量红 */
--blue:   #3E7EC7;   /* 面板蓝 */
--blue-d: #1E3D6E;   /* 页脚深蓝 */
--yellow: #F7D13C;   /* 强调黄 */
--pink:   #E85C93;   /* 台词区粉 */
--ink:    #121212;   /* 描边黑 */
--paper:  #FFFDF5;   /* 纸白 */
```

**分镜色块节奏**（蓝 → 黄 → 蓝 → 粉 → 红 → 深蓝）：
首屏蓝 → 故事蓝 → CTA 黄条 → 技能黄 → 作品蓝 → 台词粉 → 联系红 → 页脚深蓝。

**排版原则**：粗描边字体**只用于标题**，正文一律系统字体。
（这是漫画风能读的前提，一旦正文也用描边字就会失去可读性。）

## 5. 字体选型与许可核验（本轮的重点）

### 5.1 为什么不能直接用系统字体

系统字体（Impact / 微软雅黑）在中文标题上做不出漫画感，用户也选择了引入开源字体。

### 5.2 选型

| 用途 | 字体 | 原因 |
|---|---|---|
| 拉丁字母 / 数字 | **Bangers** | 经典漫画体，Google Fonts 收录 |
| 中文 | **ZCOOL KuaiLe（站酷快乐体）** | 少见的**中文漫画风**开源字体，与 Bangers 气质互补 |

### 5.3 许可核验（黄灯资源必做）

**没有直接相信"Google Fonts 上能下载就是免费"**，而是拉取了两份 `OFL.txt` 原文逐字阅读：

1. **License**：均为 SIL Open Font License 1.1；
2. **可商用**：OFL 允许任何用途（含商用），仅禁止**单独出售字体本身**；
3. **署名要求**：OFL 不要求"署名"这一形式，但 §2 要求**随字体分发版权声明与授权全文**；
4. **可否修改/再发布**：允许；子集化属于 Modified Version，须继续以 OFL 分发。

**关键发现**：两份 `OFL.txt` 在版权声明之后**均未声明 Reserved Font Name**。
按 OFL §3，只有"使用了 Reserved Font Name 的**修改版**"才禁止沿用原名。
既然没有 RFN，**我们的子集化版本可以继续使用原字体名**，无需改名。

> 这一步如果跳过，很可能踩到 RFN 的坑——这是很多"免费字体"项目实际违规的地方。

### 5.4 落地方式：自托管 + 子集化

**问题**：直接引 Google Fonts CDN 有两个毛病——
① 国内网络访问不稳定；② 运行时要产生外部请求，违背 V2 以来"零外链"的路线。

**方案**：把字体**下载下来自己托管**。但中文字体完整包动辄 5–10 MB，不能直接塞进仓库。

**解法**：利用 Google Fonts 的 `text=` 参数，**只请求页面实际用到的字形**：

```
https://fonts.googleapis.com/css2?family=ZCOOL+KuaiLe&text=<页面用到的237个字>&display=swap
```

返回的 CSS 里就是**一个只含这 237 个字形的 woff2**。

**结果**：

| 文件 | 原始 | 子集化后 |
|---|---|---|
| Bangers（拉丁） | ~30 KB | **11 KB** |
| ZCOOL KuaiLe（中文 237 字） | ~5 MB+ | **24 KB** |
| **合计** | — | **35 KB**（比一张图还小） |

**授权合规动作**：`assets/fonts/` 下随附 `OFL-Bangers.txt` 与 `OFL-ZCOOL-KuaiLe.txt` 授权全文，
并写了 `README.md` 说明来源、子集化范围与**重建步骤**。

**已知副作用（已记录）**：子集是静态的——**以后在页面上新增汉字，必须重新生成子集**，
否则新字会回退到系统字体，视觉上会不一致。重建命令已写在字体目录的 `README.md` 里。

> 技术术语：`子集化（subsetting）`、`自托管（self-hosting）`、`font-display: swap`、
> `unicode-range`、`Modified Version`、`Reserved Font Name`。

### 6.2 页面结构

| 区块 | 内容 |

| 01 故事开场 | 3 格分镜，Emoji 角色 + 气泡讲述本人信息 |
| CTA 黄条 | 引导到作品区 + CSS 自绘条码 |
| 02 技能与兴趣 | 6 张面板（技术栈 chips + 篮球 / 唱跳 rap / 文史哲 / Vibe Coding / 坐标） |
| 03 近期战绩 | 6 张作品面板（V1 / V2 / 课设 / 小实验 / 数字分身 / 待补充） |
| 04 我的台词 | 3 条左右交错的对话气泡（**本人独白，不伪造他人评价**） |
| 05 联系 | 大标题 + `mailto:` 按钮 + 条码 |
| 页脚 | 超大 `刘俊廷` + 导航 + **字体与素材合规声明** |

### 6.3 交互（`js/main.js`，零依赖）

1. **滚动淡入**：`IntersectionObserver`，`threshold 0.12`，进入视口后 `unobserve`；
2. **导航锚点高亮**：第二个 `IntersectionObserver`，`threshold 0.4`，写 `aria-current`。

### 6.4 无障碍与健壮性

- `<a class="skip">跳到主要内容</a>`（聚焦时出现）；
- `:focus-visible` 黄色虚线描边，键盘可达；
- `prefers-reduced-motion: reduce` 时**关闭全部动画与平滑滚动**；
- 语义化标签（`header / main / section / article / aside / footer / nav`）+ `aria-label`；
- 装饰性元素（天际线、网点、爆点、条码、Emoji）一律 `aria-hidden="true"`。

## 7. 踩坑与修复（记录一个真实 Bug）

**现象**：最初 `.reveal { opacity: 0 }` 是默认值，靠 JS 加 `.is-visible` 才显示。

**问题**：如果 JS 加载失败（网络、语法错误、被拦），**整页内容会永久不可见**——
这是一个白屏级故障。

**修复**：改为"**默认可见，只有 JS 可用时才隐藏**"：

```html
<!-- <head> 内联，早于渲染 -->
<script>document.documentElement.classList.add("js");</script>
```
```css
/* 默认可见；只有 <html class="js"> 时才隐藏 */
html.js .reveal { opacity: 0; transform: translateY(22px); }
html.js .reveal.is-visible { opacity: 1; transform: none; }
```

> 原则：**渐进增强（progressive enhancement）**——先把内容交付出来，
> 再用 JS 加效果，而不是让效果成为内容的门票。
