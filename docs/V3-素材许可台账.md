## 二、黄灯资源许可核验（四要点）

### R-102 Bangers

| 核验项 | 结论 |
|---|---|
| 1. 是什么许可？ | SIL Open Font License, Version 1.1 |
| 2. 是否允许商用？ | ✅ 允许。OFL 允许自由使用、研究、修改、再分发，**不限制商业用途**；唯一限制是不得**单独出售字体本身**（§1） |
| 3. 是否需要署名？ | OFL 不要求"署名"这一形式，但要求**随字体分发版权声明与授权全文**（§2）。本项目已在同目录放置 `OFL-Bangers.txt` ✅ |
| 4. 是否允许修改和再发布？ | ✅ 允许（§3、§5）。本项目的 `text=` 子集化属于 Modified Version，仍以 OFL 分发 ✅ |

**关键核验**：OFL.txt 中版权声明之后**没有 Reserved Font Name 声明**，
因此按 §3，子集化后的版本**可以继续使用原名**，无需改名。已逐字阅读原文确认。

### R-103 ZCOOL KuaiLe

| 核验项 | 结论 |
|---|---|
| 1. 是什么许可？ | SIL Open Font License, Version 1.1 |
| 2. 是否允许商用？ | ✅ 允许（同 OFL §1） |
| 3. 是否需要署名？ | 需随附版权声明与授权全文（§2），已放置 `OFL-ZCOOL-KuaiLe.txt` ✅ |
| 4. 是否允许修改和再发布？ | ✅ 允许。同样**未声明 Reserved Font Name**，子集化后可用原名 ✅ |

### 子集化（Modified Version）说明

- **为什么子集化**：中文字体完整包通常 5–10 MB，直接用于静态页会影响加载。
  使用 Google Fonts 的 `text=` 接口，只请求页面实际用到的字形。
- **产物**：中文 246 个字形 → 25 KB；拉丁 → 11 KB。合计 **36 KB**。
- **遵守 OFL 的做法**：① 仅删减字形、未改动字形设计；② 继续以 OFL 分发；
  ③ 随附两份授权全文；④ 因无 RFN，保留原字体名。
- **副作用（需知）**：子集是静态的，**新增汉字必须重新生成子集**，
  否则新字会回退到系统字体。重建步骤见 `outputs/personal-homepage-v3/assets/fonts/README.md`。

## 六、设计借鉴对照：参考稿手法 → V3 实现（2026-09-10 增补）

本轮用户提供了第二份参考稿（R-104，Marble 网站存档），要求"学做法、但绝不抄袭"。
下表逐条记录**借鉴的通用手法**与**V3 的独立实现**，用于证明二者只有"思路同源"，
不存在代码或外观层面的复制。

| 通用手法（来自参考稿） | 参考稿的做法（仅供对照，**未采用**） | V3 的独立实现 | 是否相似 |
|---|---|---|---|
| 分区滚动进度线 | SVG 路径铺满分区，用 `stroke-dashoffset` 描线 + `getPointAtLength` 让圆点沿线移动；线宽 60px、红色 | **纯 CSS 结构 + CSS 变量**：每个分区一根 `.rail`，内含 `.rail__track` / `.rail__fill` / `.rail__dot`；脚本只写入 `--p`（0~1），竖轨走 `scaleY`、窄屏横条走 `scaleX`；线宽 15px，黄→红渐变，白底 + 墨黑描边 | ✗ 结构、技术手段、尺寸、配色均不同 |
| 卡片边框状态切换 | 常态细描边，悬停时边框转红**并把整块卡片反色填充** | `.panel` 常态 4px 墨黑描边 **+ 左侧 13px 分区强调色带**；悬停时描边整体换成强调色、色带退回墨黑（**只换颜色，不反色整块**） | ✗ 描边粗细、配色、状态变化方向均不同 |
| 短横分隔线 | 极细（1px）浅色实线，固定短宽，居中 | `.rule`：墨黑**虚线** + 正中一颗 **45° 菱形**（强调色填充 + 墨黑描边） | ✗ 形状（虚线 + 菱形 vs 细实线）、配色、尺寸均不同 |
| 分区强调色 | 全站单一品牌红 | 每个分区各自一个 `--accent`（蓝区黄 / 黄区红 / 粉区黄 / 红区黄），沿用本站既有的分区色块节奏 | ✗ 色彩体系完全不同 |
