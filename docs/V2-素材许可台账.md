# V2 素材许可台账（License Ledger）

> 用途：登记 V2 制作中引用或参考的**每一个**外部资源，作为交作业的版权合规附件。
> 规则：任何进入成品的素材，必须在本表登记且"许可明确"；**不明确则不用（改为自己重做）。**
> 对应要求见 `docs/V2-版权与License合规要求.md` 第 5、6、8 节。

## 一、资源登记表

| 编号 | 资源名称 | 类型 | 来源 URL | 作者/版权方 | License | 可否商用 | 是否需署名 | 可否修改/再发布 | 本项目用途 | 红黄绿灯 | 处理方式 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| R-001 |  | 图标/图片/字体/组件/模板/代码/灵感 |  |  |  | 待查 | 待查 | 待查 |  | 🟡 | 待定 |  |
| R-002 |  |  |  |  |  |  |  |  |  |  |  |  |

> 类型说明：`灵感参考` 只需登记来源与"仅借思路"；`组件/模板/代码/字体/图标/图片` 属于黄灯，必须核验许可四要点。

## 二、黄灯许可核验四要点（每个黄灯资源都要回答）

1. 这是什么许可（License）？
2. 是否允许商用？
3. 是否需要署名（Attribution）？
4. 是否允许修改和再发布？

## 三、常用开源许可速查（仅供参考，截至整理日）

| License | 可商用 | 需署名 | 可否修改/再发布 | 备注 |
|---|---|---|---|---|
| MIT | ✅ | 需保留版权声明 | ✅ | 最宽松之一 |
| Apache-2.0 | ✅ | 需保留声明/NOTICE | ✅ | 含专利授权 |
| BSD-3-Clause | ✅ | 需保留声明 | ✅ | 宽松 |
| CC0 / Public Domain | ✅ | 否 | ✅ | 相当于放弃版权 |
| CC BY | ✅ | **需署名** | ✅ | 需注明来源 |
| CC BY-SA | ✅ | 需署名 | ✅ | 衍生作品需同协议分享 |
| CC BY-NC | ❌（非商用） | 需署名 | ✅ | 不可商用 |
| GPL/AGPL | ✅ | 需保留声明 | ✅ | **衍生作品须同协议开源**，慎用于闭源作品 |
| 无 License（All Rights Reserved） | ❌ | —— | ❌ | **默认保留所有权利，不可用** |

> ⚠️ 提醒：**Free ≠ Copyright Free**（免费 ≠ 无版权）；**Public ≠ Open Source**（公开 ≠ 开源）。标"免费下载"不等于可自由使用。
