## 二、黄灯许可核验四要点（每个黄灯资源都要回答）

1. 这是什么许可（License）？
2. 是否允许商用？
3. 是否需要署名（Attribution）？
4. 是否允许修改和再发布？

## 三、常用开源许可速查（仅供参考，截至整理日）

| License | 可商用 | 需署名 | 可否修改/再发布 | 备注 |
|---|---|---|---|---|
| MIT | ✅ | 需保留版权声明 | ✅ | 最宽松之一 |
| Apache-2.0 | ✅ | 需保留声明/NOTICE | ✅ | 含专利授权 |
| BSD-3-Clause | ✅ | 需保留声明 | ✅ | 宽松 |
| CC0 / Public Domain | ✅ | 否 | ✅ | 相当于放弃版权 |
| CC BY | ✅ | **需署名** | ✅ | 需注明来源 |
| CC BY-SA | ✅ | 需署名 | ✅ | 衍生作品需同协议分享 |
| CC BY-NC | ❌（非商用） | 需署名 | ✅ | 不可商用 |
| GPL/AGPL | ✅ | 需保留声明 | ✅ | **衍生作品须同协议开源**，慎用于闭源作品 |
| 无 License（All Rights Reserved） | ❌ | —— | ❌ | **默认保留所有权利，不可用** |

> ⚠️ 提醒：**Free ≠ Copyright Free**（免费 ≠ 无版权）；**Public ≠ Open Source**（公开 ≠ 开源）。标"免费下载"不等于可自由使用。

## 四、V2 实际使用素材确认（2026-09-10）

V2 页面 `outputs/personal-homepage-v2/` **未使用任何外部素材**：

| 项目 | 实际使用 | 版权状态 |
|---|---|---|
| 字体 | 系统字体栈（system-ui / PingFang SC / 微软雅黑 等） | ✅ 无外链、无版权风险 |
| 图标 | Emoji（Unicode 字符，如 🏀🎤💻） | ✅ 系统字符，可自由使用 |
| 插画/图片/照片 | **未使用**（头像为 "LJT" 文字占位） | ✅ 无 |
| 组件 / 模板 / 代码 | **未复制**（全部自行编写） | ✅ 无 |
| 配色 / 布局 / 交互 | 借鉴参考站**思路**，自行实现 | 🟢 绿灯 |

> 对比说明：V1 曾通过 Google Fonts 外链引入 Inter 字体；V2 已改为系统字体栈，**移除了该外链依赖**，进一步降低风险。
